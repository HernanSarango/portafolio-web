# Portafolio Web - Hernán Alfredo Sarango Noboa

## Descripción

Portafolio web personal desarrollado para presentar mi perfil académico,
habilidades técnicas y proyectos realizados durante mi formación en
Ingeniería en Software.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Características

- Diseño responsive.
- Tema oscuro.
- Navbar adaptable.
- Sección de proyectos.
- Design System.
- Validación de formulario.
- Animaciones mediante JavaScript.

## Proyectos destacados

### Aplicación Médico

Sistema web orientado a la gestión de procesos médicos utilizando
Python, Django y PostgreSQL.

### Mapa Escolar Parlante

Prototipo basado en Arduino orientado a mejorar la accesibilidad
educativa mediante interacción táctil y salida de audio.

### NutriScan Kids

Plataforma web enfocada en el análisis y seguimiento nutricional infantil.
